# Contributing to QuantumLink

Thank you for taking an interest. This repository holds documentation only. QuantumLink's source code is not
published here, so code pull requests cannot be accepted.

## What helps most

- **Questions** about how QuantumLink works or what it is for.
- **Design critique.** Tell us where the architecture or security model is
  unclear, inconsistent, or wrong.
- **Use cases.** Describe what you need to protect or assess, and what would
  have to be true for you to rely on QuantumLink.
- **Documentation fixes.** Typos, broken links, and unclear wording. Pull
  requests are welcome for these.

Use Issues for specific problems and requests, and Discussions for open
questions and ideas.

## Not here

- **Vulnerabilities.** Report them privately; see [SECURITY.md](SECURITY.md).
- **Sensitive data.** Do not post keys, credentials, customer data, or
  internal network details in issues or discussions.

## Pull requests

Documentation pull requests from outside contributors need a
[Developer Certificate of Origin](https://developercertificate.org/) sign-off
on each commit (`git commit -s`). By contributing, you agree that your
contribution is licensed under [CC BY 4.0](LICENSE), the license of this
repository.

## Conduct

The DytallixHQ [code of conduct](https://github.com/DytallixHQ/.github/blob/main/CODE_OF_CONDUCT.md)
applies to every space in this repository.
